============================================================
   STAND AUTOMÓVEL - GUIA RÁPIDO DE INSTALAÇÃO
============================================================

1. EXTRAIR FICHEIROS
   - Extrair SAW_Projeto_Completo.zip
   - Colocar pasta "saw_project" no servidor web (ex: htdocs/)

2. CRIAR BASE DE DADOS
   - Abrir MySQL/phpMyAdmin
   - Executar o ficheiro: database.sql
   - Isto cria a base de dados "stand_automovel" com dados de teste

3. CONFIGURAR APLICAÇÃO
   - Editar: config/config.php
   - Ajustar DB_USER e DB_PASS conforme necessário
   - Ajustar SITE_URL para o seu ambiente

4. PERMISSÕES (Linux/Mac)
   chmod 755 -R public/uploads/

5. ACEDER À APLICAÇÃO
   http://localhost/saw_project/public/index.php
